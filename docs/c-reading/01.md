## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-01.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/01/main.c -o reading-01
./reading-01
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
3.305 V
```

3305 / 1000 得到 3，余数是 305。%03u 把小数部分补足三位。

</details>

## 练习

把输入改成 3005，预测小数点后会显示几位。
