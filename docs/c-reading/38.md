## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-38.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/38/main.c -o reading-38
./reading-38
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
2A 12 34
```

类型 2A、序号 1234 要发送的三个字节是 2A 12 34。结构体的成员偏移可以因平台改变。

</details>
