## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-22A.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/22A/main.c -o reading-22A
./reading-22A
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
3 A5 2A D5
0 CC
0
```

容量 3 时返回 3。容量 2 和 0 时返回 0，调用者用哨兵值 CC 核对短缓冲区未被部分写入。零容量演示允许传入空指针。

</details>
