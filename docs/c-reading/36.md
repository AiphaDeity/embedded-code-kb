## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-36.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/36/main.c -o reading-36
./reading-36
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
ok 25
retry 25
fault 25
ok 27
```

用脚本喂入成功 25、失败、失败、成功 27。两次失败期间上次有效值保持 25，恢复后更新为 27。

</details>

## 练习

把脚本改成从失败开始，检查首次成功之前打印的是空值。再设计需要连续两次成功才恢复的版本。
