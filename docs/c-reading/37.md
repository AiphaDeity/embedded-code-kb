## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-37.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/37/main.c -o reading-37
./reading-37
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
2 1
```

模拟读数从 1 开始递增。宏比较时读 1，返回时再读出 2；重置后函数只读取 1。

</details>

## 练习

用 gcc -E main.c 查看 main 内的宏展开，再判断哪次读取可以省掉。
