## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-06.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/06/main.c -o reading-06
./reading-06
```

先沿 `main()` 预测打印结果，再展开核对。
