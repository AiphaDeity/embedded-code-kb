## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-02.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/02/main.c -o reading-02
./reading-02
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
normal warm hot
```
