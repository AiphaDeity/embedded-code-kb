## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-31.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/31/main.c -o reading-31
./reading-31
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
0 1 -1 0
```

前两次取到 0、1，池满返回 -1。归还 0 后再次取到 0。

</details>

## 练习

让 release 返回布尔值，区分重复归还和成功归还。
