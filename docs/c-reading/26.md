## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-26.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/26/main.c -o reading-26
./reading-26
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
5:1
```

输入 1、0、1、1、1，在第 5 次采样才稳定按下。

</details>

## 练习

继续输入三个 0，判断何时报告释放。
