## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-41.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/41/main.c -o reading-41 -Wl,-Map=reading-41.map
./reading-41
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
10
```

零初始化缓存的第 0 项为 0，gain 初值 3，table 第 1 项为 7，相加得到 10。

</details>

## 练习

执行 gcc -O0 main.c -Wl,-Map=lesson.map -o lesson，在 map 中查全局符号 gain、cache、table，再用调试器查看局部变量 total。

打开生成的 `reading-41.map`，再用 `nm -S reading-41` 对照对象名称。不同主机工具链的段落名和地址可能有所不同。
