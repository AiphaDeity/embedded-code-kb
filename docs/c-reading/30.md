## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-30.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/30/main.c -o reading-30
./reading-30
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
2:11:22
0
```

第一批在首个数据字节后结束。第二批补齐 22，随后一个零长度帧也完成。

</details>
