## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-40.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/40/main.c -o reading-40
./reading-40
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
2
```

网关收到 2、3、7、1，满足阈值 3 的元素有 2 个。编译器可以内联或折叠计算。

</details>

## 练习

分别执行 gcc -O0 -S main.c -o slow.s 和 gcc -O2 -S main.c -o fast.s，在 main 附近找计数循环或已经算出的结果。

对同一份源码分别运行 `gcc -std=c11 -O0 -S` 和 `gcc -std=c11 -O2 -S`，用 `-o` 指定两个不同的汇编输出文件，再定位循环。
