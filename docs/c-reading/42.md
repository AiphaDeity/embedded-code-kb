## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-42.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/42/main.c -o reading-42
./reading-42
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
good=2 bad=1 last=42
```

三批输入包含噪声、一个坏帧和两个好帧。第一帧跨批完成，坏帧丢弃后继续接收，末帧交付 42。

</details>

## 练习

把每个字节单独分批，结果应相同。再截掉最后一个校验字节，检查好帧数、坏帧数、上次有效值与当前状态。

阶段自测　尝试将第 28 题与第 42 题连接，覆盖正常帧、坏帧和队列满，再打开结课项目对照。
