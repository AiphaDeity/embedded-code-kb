## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-13.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/13/main.c -o reading-13
./reading-13
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
-1 255
```

uint8_t 的 0 和 1 提升为 int 后相减得到 -1。转换到 uint8_t 得到 255。

</details>
