## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-25.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/25/main.c -o reading-25
./reading-25
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
7 due
```

起点为 0xFFFFFFFC，当前为 3，经过 7 个 tick。前提是实际间隔小于一个完整的 32 位计数周期。

</details>
