## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-20.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/20/main.c -o reading-20
./reading-20
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
-5 C
```

事件的标签是 TEMPERATURE，读取同一次初始化的 celsius 成员。
