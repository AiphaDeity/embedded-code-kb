## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-19.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/19/main.c -o reading-19
./reading-19
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
2 1
```

a 收到两次采样，b 收到一次，两份状态独立。
