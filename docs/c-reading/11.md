## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-11.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/11/main.c -o reading-11
./reading-11
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
3 12
```

从 8 初始化两个极值，3 更新最小值，12 更新最大值。约定两个输出指针指向不同的有效对象。

</details>
