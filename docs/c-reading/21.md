## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-21.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/21/main.c -o reading-21
./reading-21
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
1 2
```

两次调用共享同一个 count，值从 0 变成 1，再变成 2。两个调用分开成两条语句。

</details>
