## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-17.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/17/main.c -o reading-17
./reading-17
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
-1 -2048 2047
```

0xFFF 表示 -1，0x800 表示 -2048，0x7FF 表示 2047。

</details>
