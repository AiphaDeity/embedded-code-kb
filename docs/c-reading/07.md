## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-07.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/07/main.c -o reading-07
./reading-07
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
1
```

第 1、2 号元素都达到 20，第一次命中下标 1。没有匹配时返回 n。
