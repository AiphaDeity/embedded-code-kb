## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-00.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/00/main.c -o reading-00
./reading-00
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
34
```

stdio.h 提供 printf 的声明。unsigned 表示无符号整数，变量 reading 保存 17。twice 收到一份值的副本，返回 34。%u 以十进制输出 unsigned，最后的 return 0 表示正常结束。

</details>
