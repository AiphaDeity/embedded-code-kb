## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-18.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/18/main.c -o reading-18
./reading-18
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
F4
```

输入 ASCII 字节 31 至 39，校验结果为 F4。空输入保留初值 0。

</details>
