## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-16.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/16/main.c -o reading-16
./reading-16
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
4660
```

12 34 表示十六进制 0x1234，即十进制 4660。

</details>
