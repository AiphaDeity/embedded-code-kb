## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-32.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/32/main.c -o reading-32
./reading-32
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
04
```

初值 0x05。同时挂起 bit 0 和 bit 2。总线上写 0x01 后只剩 bit 2。

</details>
