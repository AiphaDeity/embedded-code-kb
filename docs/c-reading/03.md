## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-03.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/03/main.c -o reading-03
./reading-03
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
sum=100 mean=25
```

sum 依次成为 10、30、60、100。整数平均值是 25。

</details>
