## 主机运行

在仓库根目录执行。Windows 可以将输出名写成 `reading-14.exe`，再从终端运行。

```sh
gcc -std=c11 -Wall -Wextra -pedantic examples/c-reading/14/main.c -o reading-14
./reading-14
```

先沿 `main()` 预测打印结果，再展开核对。

<details><summary>主机输出与手推</summary>

```text
02 1
```

0x08 置位 bit 1 得到 0x0A，再清 bit 3 得到 0x02。

</details>
